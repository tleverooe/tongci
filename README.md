# 同词相见

**在线玩：https://tleverooe.github.io/tongci/**

一个测试默契的多人联想小游戏。两到四个人各写一个词，没对上就从大家上一轮的词里继续联想，直到所有人写出同一个词，就算"相见"了。用了几轮才相遇，就是你们脑回路的距离。

## 怎么玩

1. 一个人填好昵称，点"创建新房间"。
2. 把房间码或邀请链接发给朋友，朋友填昵称加入。
3. 人到齐后，房主点"开始游戏"。
4. 第一轮每人随便写一个词。揭晓后如果不一样，下一轮就要想一个能同时联系上大家上一轮那些词的新词。
5. 一直到所有人在同一轮写出同一个词，游戏结束，结尾会列出每一轮大家写了什么。

举个例子：一个人写"月亮"，另一个人写"兔子"，下一轮两个人都往"玉兔"想，就相遇了。

## 房间设置

房主可以在开始前调整：

- **房间人数**：2、3 或 4 人
- **每轮思考时间**：30 秒、60 秒或自定义（10–300 秒）
- **能否重复用之前出现过的词**：默认允许

## 小规则

- 比较时不区分大小写，也忽略空格和标点，所以"玉兔"和"玉 兔！"算同一个词。
- 时间到了没提交算超时；输入框里打好但没点提交的词会被自动交上去。
- 有人中途掉线，游戏不会卡住，剩下的人可以继续；房主离开后会自动换人当房主。
- 不用注册登录，用昵称就能玩。
